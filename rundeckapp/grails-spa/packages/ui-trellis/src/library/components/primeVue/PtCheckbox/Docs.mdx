## Usage

`PtCheckbox` is the bare checkbox control. Associate it with an external
`label` through `inputId`; item-level label, description, icon, and layout
belong to the consuming feature.

## Accessibility

Provide either an associated `label`, `ariaLabel`, or `ariaLabelledby`.
PrimeVue supplies the hidden native checkbox and standard Space-key behavior.
