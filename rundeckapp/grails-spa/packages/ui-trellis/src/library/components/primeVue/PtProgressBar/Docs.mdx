## How to use

Pass `value` (0-100; out-of-range values are clamped, unlike raw PrimeVue which overflows). Use `mode="indeterminate"` when progress is unknown and `showValue=false` to hide the label. The default slot replaces the `N%` label. No striped variant; styling follows the library tokens (no Figma spec).

## Accessibility

Renders `role="progressbar"` with `aria-valuemin`/`aria-valuenow`/`aria-valuemax` (clamped). Pass `ariaLabel` or `ariaLabelledby` to describe it. In determinate mode a visually hidden `progress.bar.percent.complete` ("N% Complete") label is rendered for screen readers.
