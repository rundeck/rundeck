## How to use

Bind `v-model` to open and close it. Footer buttons come from the `buttons` prop and
clicking one emits `button-click` with its `id`; the modal never closes itself, so the
parent decides what each button does. Use the default slot for the body, `header` for a
custom title and `footer` to replace the generated buttons.

```vue
<PtModal
  v-model="open"
  header="Discard this step?"
  :buttons="[
    {
      id: 'keep',
      label: 'Keep editing',
      severity: 'secondary',
      outlined: true,
    },
    { id: 'discard', label: 'Discard', severity: 'danger' },
  ]"
  @button-click="onButton"
>
  Your progress will be lost.
</PtModal>
```
